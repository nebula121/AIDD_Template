# ドメイン用語 ＆ ドメイン不可侵ルール

<!-- @spec:domain-rules -->

システム固有のユビキタス言語およびビジネス・データ不変条件の定義正本。共通技術制約は [../core-rules.md](../core-rules.md) を参照。

---

## 1. ユビキタス言語定義

<!-- @spec:domain-glossary -->

コード上の識別子（クラス・関数・型・DBカラム）および仕様書内の語彙は以下の定義に統一する (**MUST**)。

| 用語 | コード識別子 | 厳密な定義・責務 | 混同しやすい概念との境界 |
| :--- | :--- | :--- | :--- |
| `[要記入: 用語名]` | `[要記入: Identifier]` | `[要記入: エンティティや概念の厳密な定義]` | `[要記入: 別概念との違い・非対象範囲]` |

---

## 2. ドメイン不変条件 ＆ 検証基準

<!-- @spec:domain-invariants -->

<!-- GUIDE: 曖昧な形容詞を排し、RFC 2119 + 検証可能な条件で記述すること。
❌ Bad: 注文データは常に整合性を保ち、不正な金額にならないようにすること。
✅ Good: 注文合計金額（Order.total_amount）は0以上の整数とし、明細行の小計合計と1円単位で完全一致しなければならない (MUST)。
-->

| ルールID | 対象エンティティ / 領域 | ドメイン不変条件契約 (`MUST` / `MUST NOT`) | 機械的検証基準 |
| :--- | :--- | :--- | :--- |
